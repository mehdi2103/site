FAQ

Quick answers to common questions.

How do I deploy this?
Export this file as index.html and drop it into Netlify, Vercel, or GitHub Pages. No build step required.
Can I change colors and fonts?
Yes — update the :root CSS variables for brand colors, radius, and shadows.
Is dark mode included?
Yep! It respects system theme and lets visitors toggle themes. Preference is saved in localStorage.
